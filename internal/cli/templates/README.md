# kempt config

A [kempt](https://kempt.tools) config repo — your machine described in one
`kempt.toml`.

## Use it

Install kempt, then apply this config on any machine:

```sh
curl -fsSL https://kempt.tools/install.sh | sh
kempt init <this-repo-url>
```

Edit `kempt.toml` to taste and run `kempt lint` to check it.
